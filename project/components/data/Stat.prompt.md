The data-driven hero metric — huge thin number, mono label, optional delta.

```jsx
<Stat label="Total Reach" value="12.4M" delta="+38%" caption="Impressions across the campaign window." />
<Stat label="Budget" value="₩819M" accent size="md" />
```

Props: `value`, `label`, `caption`, `delta` + `deltaDir`, `accent`, `size` (sm/md/lg), `align`.
