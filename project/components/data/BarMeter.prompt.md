Horizontal labelled bar for budget breakdowns and KPI progress rows.

```jsx
<BarMeter label="Production" value="₩320M" pct={42} color="var(--spectral-amber)" />
<BarMeter label="Hardware" value="₩240M" pct={31} color="var(--spectral-slate)" />
```

Stack several for a budget split. `color` accepts any spectral/champagne token.
