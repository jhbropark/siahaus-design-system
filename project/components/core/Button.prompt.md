Mono-label button for CTAs and navigation — uppercase, tracked, near-square.

```jsx
<Button variant="primary" size="md">View Proposal</Button>
<Button variant="secondary">Download Deck</Button>
<Button variant="ghost" size="sm">Skip</Button>
```

Variants: `primary` (champagne on ink), `secondary` (hairline outline), `ghost` (text only).
Sizes: `sm` / `md` / `lg`. Props: `full`, `disabled`, `iconLeft`, `iconRight`.
